* **`display`**: Defines how an element is displayed (block, inline, flex, grid, inline-block, inline-flex, none.).
* **`table`**: Used to display an element like a table (rows, columns).
* **`max-min`**: Controls the maximum and minimum size of an element.
* **`position`**: Determines how an element is positioned on the page (static, relative, absolute, fixed).
* **`z-index`**: Controls the stacking order of elements (higher numbers are on top).
* **`overflow`**: Determines how content behaves when it overflows its container (scroll, hidden, visible).
