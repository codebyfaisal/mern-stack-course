# Programming

Programming is a way (method) to communicate (chat) with a computer. Just like we humans need a language to communicate with each other, a computer also needs a language to understand our instructions. But a computer does not understand languages like Urdu, English, or Pashto.

So, we need a translator that can translate from Urdu to English and vice versa — in this case, into a language that a computer can understand.
For this purpose, programming languages are used to communicate with computers.

There are many programming languages like **C, C++, Java, Python, JavaScript**, etc.

### Definition

Programming is the process of writing instructions for a computer to perform a specific task. It involves creating a set of commands, or code, in a specific programming language, which a computer can then follow to solve problems or execute functions.

# JavaScript

JavaScript was created by **Brendan Eich** in just **10 days** in april 1995 at **Netscape Communications** as name of **Mocha**. Later, it was renamed to **LiveScript** and then finally to **JavaScript**.

## Definition
JavaScript is a dynamic programming language that tells the computer what to do and how to do it.

For example, if we ask a human, “What is the answer to 2 + 2?”, they will say **4**.
But if we ask a computer, “What is the answer to 2 + 2?”, the computer will not understand until we tell it **how** to calculate it.

This means a computer is a dumb machine — it does not understand anything until we give it exact instructions.
That’s where programming languages come in, and one of these languages is **JavaScript** (which we will learn in this course).

`JavaScript was originally created as a scripting language for web browsers — to add interactivity and control webpage behavior (like responding to button clicks or validating forms).`

# ECMAScript

JavaScript is based on a programming language standard called **ECMAScript**.
**ECMAScript** is a standard that defines how scripting languages like JavaScript should work.

# Do we need to install JavaScript?

No, you don't need to install JavaScript. You can use JavaScript directly in your web browser — there’s no separate installation required.

So, you only need a browser. That’s all.

## Scripting Languages vs. Programming Languages

* **Scripting languages** are often used to create interactive web pages.
* **Programming languages** are used to write complete computer programs and applications.

---

## Is JavaScript a Programming Language or a Scripting Language?

JavaScript was originally created as a **scripting language** for web browsers — to add interactivity and control webpage behavior (like responding to button clicks or validating forms).

The term *“scripting”* means writing small pieces of code (scripts) that automate tasks or control other software.

But, after the rise of **Node.js**, JavaScript also became a **programming language** by supporting server-side programming — meaning it can now interact directly with databases and computer systems.

👉 **In short:**
**JavaScript = Scripting Language (originally) + Programming Language (today)**
