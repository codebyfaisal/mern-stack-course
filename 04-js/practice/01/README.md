### **1. Conditionals**

1. Get the user age using `prompt()`.

    * Below 18 → print "`You are not eligible to vote`"
    * Above 18 → print "`You are eligible to vote`"

2. Ask the user to enter a number.

   * Print whether it is **positive**, **negative**, or **zero**.

3. Get a password from the user using `prompt()`.

   * If the password is `"1234"` or `"password"` → print "`Access granted`"
   * Else → print "`Wrong password`"

4. Get a number from the user using `prompt()`.

   * Print `"Even"` if the number is even
   * Print `"Odd"` if the number is odd

5. Get a number(just like marks) from the user using `prompt()` only(1 to 100).

   * Print `"Grade A"` if the marks are between 80 and 100
   * Print `"Grade B"` if the marks are between 60 and 79
   * Print `"Grade C"` if the marks are between 40 and 59
   * Print `"Grade D"` if the marks are between 0 and 39
   * Print `"Fail"` if the marks are less than 0
